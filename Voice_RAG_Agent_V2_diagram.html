Data Flow

  1. Webhook receives a POST with the user's query and optional contact fields (name, email, phone, date, time).
  2. AI Agent (powered by Gemini Flash) receives the prompt and decides which tool(s) to invoke.
  3. 5 tools are wired to the agent:
    • SerpAPI — live Google search for general knowledge
    • Get_Available_Slots — checks Google Calendar ±1 day around the requested date
    • Book_Meeting — creates a calendar event with the attendee, time, and summary
    • Contact Information — appends name/email/phone to a Google Sheet
    • Data_Base — RAG-powered lookup of AI Kit Pro services via Supabase pgvector
  4. Data_Base has its own LLM (OpenAI) and pulls embeddings from the Supabase Vector Store (which uses OpenAI embeddings).
  5. Respond to Webhook returns the final agent output as JSON.

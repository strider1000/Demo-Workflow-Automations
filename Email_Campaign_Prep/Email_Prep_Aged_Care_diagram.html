Active Path — Step by Step

  1. Manual Trigger — operator clicks "Test workflow" to start.
  2. Get row(s) in sheet — reads from Google Sheets ("Aged Care Leads" tab), filtering rows where Ready = Yes and Processed = No.
  3. Limit — caps at 500 rows per run.
  4. Loop Over Items — SplitInBatches processes each row individually. Output 1 feeds the script generator.
  5. Script Option 4 — an LLM Chain (powered by OpenRouter Chat Model 4) that writes 3 casual, peer-to-peer cold emails introducing Evaheld (advance care planning platform). Uses prospect research data. Outputs JSON with subject + 3 email bodies.
  6. Split emails — a Set node that strips ```json``` wrappers from the LLM output.
  7. Append or update row in sheet — writes the generated V2 Subject, V2 Email #1/#2/#3 back to the same Google Sheet, matched on Email, and sets Processed = Yes.
  8. Loops back to Loop Over Items for the next row.
